# Installation

Leantime can be installed in different ways. The following are few options of installation:

- [Package based installation](installation/package-installation.md)
- [Shared hosting (cPanel)](installation/shared-hosting.md)
- [Docker based installation](installation/docker.md)
    - [Synology NAS](installation/synology.md)
    - [Kubernetes (Helm)](installation/kubernetes.md)
- [Portainer, TrueNAS, Unraid and Raspberry Pi](installation/other-methods.md)
- [One-click installs (Coolify, Dokploy, Easypanel and others)](installation/one-click-installs.md)

## Can someone install Leantime for me?

Yes. If you'd rather not install Leantime yourself, the Leantime team can install it on your server, or install it and keep it maintained and up to date. These are paid services; see the [Leantime Marketplace](https://marketplace.leantime.io/) for the installation and support plans.

To do it yourself with help from other users, ask in the [community chat](https://discord.gg/4zMzJtAq9z).
