There are two ways to use Leantime. Only the first step differs: on Leantime Cloud you start a trial, and on your own server you install Leantime first. After that, everything works the same.

## How do I start with Leantime Cloud?

1. **Start a free two-week trial** at [accounts.leantime.io](https://accounts.leantime.io/accounts/register/). Your workspace gets its own address, like yourteam.leantime.io.
2. **Sign in and look around.** Cloud includes the marketplace plugins and the AI features inside Leantime. The exception is [Advanced Authentication](/plugins/advanced-authentication/) (SAML and sign-in with Google, Microsoft, GitHub and others), which is for self-hosted servers only. To see which features are core and which come from a plugin, see [What can Leantime do?](/getting-started/features/)
3. **Invite your team** from **Company → User Management** (see [User Management](/using-leantime/user-management/)).

To keep going after two weeks, add a card. If you don't, your workspace is paused and kept for 180 days, so you can come back to it. To pick it up again, email support@leantime.io. To remove it sooner, delete it yourself (see [Delete your Leantime Cloud account](/using-leantime/delete-cloud-account/)). The [privacy policy](https://leantime.io/privacy/) has the details.

## How do I install Leantime on my own server?

1. **Check what your server needs.** With Docker, you only need Docker with Docker Compose: the image brings PHP, and the example setup starts the database. For a package installation, you need PHP 8.2 or later and MySQL 8.0+, MariaDB 10.6+ or PostgreSQL (see [System requirements](/installation/system-requirements/)).
2. **Install Leantime.** With [Docker](/installation/docker/) it takes about 10 minutes. You can also install it [on a server with PHP and MySQL](/installation/package-installation/).
3. **Create the first account.** The first person to finish the installer becomes the Owner.
4. **Invite your team** from **Company → User Management** (see [User Management](/using-leantime/user-management/)). Sending invitations needs [email set up](/installation/email-configuration/).
5. **Optional: add plugins** from the [marketplace](https://marketplace.leantime.io/), for example Strategies and Programs, or Advanced Authentication for the mobile app (see [Plugins](/installation/plugin-installation/)).

The open source edition is free under the AGPLv3 license. You can move a self-hosted Leantime to Cloud later.

## What should I do first in Leantime?

Whichever you chose:

1. **Decide how to organize your work.** A few minutes here saves a lot of moving things around later; see [How should I organize my work in Leantime?](/getting-started/organize-your-work/)
2. **Set up your first project** (see [Projects](/using-leantime/managing-projects/#how-do-i-create-a-project-in-leantime)).
3. **Open My Work** to see your day: your to-dos from every project, and a calendar to plan your time (see [My Work Dashboard](/using-leantime/my-work-dashboard/)).
